🌐

Web版 (ブラウザ / iPhone)

インストール不要。ブラウザで今すぐ編集を開始できます。iPhone / iPad / PCすべてに対応。

Web版を今すぐ開く ▶
📱 iPhoneでのアプリ化手順:
  1. Safariで上記ボタンから開く
  2. 画面下の共有アイコン（↑）をタップ
  3. 「ホーム画面に追加」 を選択
※URLバーのない全画面アプリとして起動します
🪟

Windows 版

専用デスクトップアプリとして利用可能。インストーラー不要で解凍してすぐに起動できます。

📥 Windows版をダウンロード (.zip)
💻 使い方:
  1. ダウンロードした ZIP を右クリック →「すべて展開」
  2. フォルダ内の MultiTrackVideoEditor.exe をダブルクリック
※管理者権限・インストール作業不要
🐧

Linux 版

Ubuntu / Debian / Fedora / Arch など主要なLinuxディストリビューションで利用可能です。

📥 Linux版 (AppImage) をダウンロード
🐧 使い方:
  1. ファイルを右クリック → プロパティで「実行可能」にチェック
  2. ダブルクリックで即座に起動（または chmod +x）
※依存関係なしで単体動作します

✨ 主な機能・特徴

🟢 クロマキー合成 動画や画像のグリーンバックをリアルタイムに自動透過。感度や輝度も微調整可能。
✏️ テキストレイヤー 自由な文字追加、フォントサイズ・文字色・縁取りカラー・太さのフルカスタマイズ。
⚡ 自動保存 (端末容量ゼロ) 編集操作をリアルタイムに自動保存。再読み込みや誤って閉じても即座に作業復元。
🎥 動画録画・保存 プレビュー内容をWebMまたはMP4でそのまま高画質エクスポート。
